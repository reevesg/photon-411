# Post-Race

## At the Finish
- [ ] Drop jib immediately
- [ ] Main — drop if conditions allow, otherwise keep up for the sail back

## Motoring Back
- [ ] All hands tidy as you go — no specific order, get on with it

## Sails & Lines
- [ ] Drop and flake main if not already done — see **Main Drop** checklist
- [ ] Lash main to boom with sail ties
- [ ] Pack kites into bags
- [ ] Flake and bag jibs
- [ ] Coil and stow all sheets, halyards, and guys
- [ ] Retract and secure bowsprit

## At the Mooring
- [ ] Pick up mooring ball and secure pendant
- [ ] Shut down engine — pull switch at engine
- [ ] Turn off all electronics — instruments and chartplotter breakers
- [ ] Final tidy of deck and cockpit
- [ ] Put main cover on
