# Pre-Start

## On Arrival at Starting Area
- [ ] Check in with race committee
- [ ] Ping the start line (note favoured end)

## Hoist & Warm-Up Sequence
- [ ] Hoist main
- [ ] Hoist headsail
- [ ] Set car position
- [ ] Go max upwind — check rig tune (runners, mast rake, jib lead)
- [ ] Tack
- [ ] Hoist kite
- [ ] Gybe
- [ ] Douse kite

## Into the Warning
- [ ] Enter pre-start sequence at warning signal
- [ ] Raise jib as needed for start
