# Main Hoist

## Key Principles
- **The boom will swing freely and dangerously before the main is up — treat with the same care as the main drop**
- Driver keeps boat pointed into the wind throughout
- Main hoists up between the active windward runner and the lazy leeward runner

---

## Prepare
- [ ] Driver: head into the wind and hold there
- [ ] Ease mainsheet, vang, outhaul, cunningham
- [ ] **Ease lazy (leeward) running back**
- [ ] Crew member pulls lazy runner forward toward the mast — creates a gap for the main to hoist into
- [ ] **Release preventer** — boom is now free, take care
- [ ] Confirm main halyard is clear and flaked, ready to run
- [ ] Remove sail ties and cover

## Hoist
- [ ] Hoist halyard from inside cabin at base of mast — hand over hand as fast as possible
- [ ] Once most of the way up: lead halyard into snatch block for fair lead to cockpit winch
- [ ] Grind halyard on cockpit winch to finish hoist — tension firm
- [ ] Confirm main is fully hoisted and halyard is secured

## Trim
- [ ] Set active windward running back
- [ ] See **Main Trim** checklist for full trim sequence
