# Reefing (Slab)

## Key Principles
- Two reef points available
- Tack handled at the mast, clew via reef line from cockpit
- Reef while sailing — keep headsail up to maintain boat speed
- **Halyard must be flaked out before reefing — will not drop if it isn't**
- **Tack strap must be pre-rigged and accessible at the mast**
- Take care that reef lines are run freely — sail can chafe on reefing line if not run properly

---

## Prepare
- [ ] Tactician or driver calls reef
- [ ] Confirm tack strap is available at the mast
- [ ] Confirm reef lines are running freely and correctly led
- [ ] Confirm halyard is flaked out and ready to run

## Depower
- [ ] Ease vang
- [ ] Ease cunningham
- [ ] Ease mainsheet — let main depower
- [ ] Headsail remains up — keep sailing

## At the Mast — Tack
- [ ] Ease halyard — lower main using slippery mast track, pulling sail down under pressure
- [ ] Lower until reef tack cringle is accessible
- [ ] Pass strap through tack cringle and around the mast — secure firmly
- [ ] Attach cunningham to tack cringle
- [ ] Hoist halyard back up — tension firm

## At the Cockpit — Clew
- [ ] Pull reef clew line — tension clew cringle down to boom
- [ ] Confirm clew is firm and reef line is not chafing the sail

## After
- [ ] Trim mainsheet
- [ ] Re-tension vang
- [ ] Re-tension cunningham as needed
- [ ] Tie in reef points if conditions allow
- [ ] Coil and secure excess lines

---

## Shaking Out a Reef
- [ ] Ease vang and cunningham
- [ ] Ease mainsheet — depower
- [ ] Ease reef clew line — release clew cringle
- [ ] At mast: remove strap from tack cringle, detach cunningham
- [ ] Hoist halyard — full main up
- [ ] Re-tension cunningham, vang, mainsheet
